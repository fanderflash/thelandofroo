# Roo social typography

Approved by Thomas Robbjens on 2026-10-20: option 2 from Roo_Typsnitt_Jamforelse.png.

Use **Cormorant Garamond SemiBold (600)** for text overlays on newly created The Land of Roo social images, carousels and Reels. This file is the exact font used to render option 2 in the comparison. Typeset text using the actual font file after generating the original artwork, so the chosen letterforms are reproducible. Keep text short, large and legible on phones, with strong foreground/background contrast.

Font: `CormorantGaramond-SemiBold.ttf`

This choice supersedes earlier notes that the font decision is pending. Use it when creating new media; recovery of existing scheduled or published content must preserve the intended media and avoid duplicates. Do not add text to an intentionally text-free image solely to demonstrate the font. This typography decision applies to social media artwork, not website CSS or locked lore.
